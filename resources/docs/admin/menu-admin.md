## Descripción

El menu principal despliega diferentes links los cuales puede acceder el usuario dependiendo de los permisos de su rol. En dispositivos como pc, tablets y laptops puedes visualizar el menu como una barra de navegación, mientras que en dispositivos móviles como menu desplegable.

## Iconos

El menu principal utiliza ciertos iconos para determinadas funcionalidades, a continuación se muestra una tabla con los iconos que se utilizan y su función.

| Icono | Función |
| : | : |
| <img src="/images/sun-horizon.png" width="25" height="25"/> <img src="/images/moon-stars.png" width="25" height="25"/> | Indica que el usuario puede cambiar el tema del sistema entre `claro` o `oscuro`.|
| <img src="/images/bell.png" width="25" height="25"/> | Indica al usuario el apartado de notificaciones, en caso de que tenga alguna notificación este mostrara un punto rojo. |
| <img src="/images/caret-down.png" width="25" height="25"/> | Icono que despliega menu con las opciones de `cerrar sesión` y `ajustes` |
| <img src="/images/question-mark.png" width="25" height="25"/> | Ubicado en la parte inferior de la pagina este apartado redirige a la `documentación` de la pagina. |
