## Editar información

Ve al apartado de **Proyectos** selecciona **Listado de proyectos**, busca el proyecto al que quieras editar información del cliente, presiona el botón <img src="/images/all/eye.png" width="25" height="25"/>, y en el menu de acciones de cliente presiona el botón <img src="/images/all/pencil.png" width="25" height="25"/> para acceder a la página donde podrás actualizar la información del cliente.

<br/>
<img src="/images/admin-img/edit-client.png" width="70%" height="70%"/>
<br/>


Actualiza la información del cliente y guarda los cambios realizados.
