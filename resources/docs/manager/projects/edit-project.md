## Editar información

Para modificar la información de un proyecto, ve al apartado **Proyectos**, selecciona **Lista de Proyectos**. Cuando localices el proyecto haz click en <img src="/images/all/pencil.png" width="30" height="30"/> para acceder a la página donde actualizarás la información del proyecto.

<br/>

<img src="/images/admin-img/edit-project.png" width="90%" height="90%"/>
<br/>

Actualiza la información del proyecto y guarda los cambios realizados.
