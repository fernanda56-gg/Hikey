## Editar estatus de proyecto

Para modificar el estatus de proyecto, ve al apartado **Proyectos** y selecciona **Lista de Proyectos**. Cuando localices el proyecto haz click en <img src="/images/all/eye.png" width="30" height="30"/> para acceder a la página de información de proyecto. Selecciona el botón que modificara el estatus de proyecto el cual dará 3 opciones: 

<ul>
<li>Iniciar proyecto: El estatus del proyecto se marca como en progreso.</li>
<li>Marcar como completado: El estatus del proyecto se marca como completado y se añade la fecha de finalización en el form de información del proyecto.</li>
<li>Reabrir proyecto: El estatus del proyecto regresa a pendiente y se elimina la fecha de finalización, esto en caso de que el proyecto necesite modificaciones.</li>
</ul>
